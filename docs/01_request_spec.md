# [요구사항 명세서] 모바일 16:9 광범위 카메라 촬영 뷰포트 정상화 및 반응형 최적화

## 1. 결함 원인 분석 (Root Cause Analysis)
- **현상:** 모바일 실제 접속 시 카메라 화면이 세로로 극단적으로 좁은 띠(폭 약 180px) 형태로 축소되고 좌우 화각이 80% 이상 잘려나감.
- **원인 분석:**
  1. **고정 가로 배치(flex-direction: row):** 모바일 세로(Portrait) 상태에서도 화면을 좌우로 분할하여 좌측 뷰포트가 180px 미만으로 압축됨.
  2. **`object-fit: cover` 크롭:** 4:3 또는 16:9 카메라 영상이 좁고 긴 세로 컨테이너에 맞춰지면서 좌우 영역이 전부 잘려나감.
  3. **카메라 제약 조건(Constraints):** `width: 640, height: 480` (4:3 비율)로 설정되어 16:9 와이드 광각 카메라 화각을 요청하지 못함.
  4. **추후 AI 학습 데이터 수집 저해:** 촬영 화면이 왜곡/크롭되면 향후 수집될 컨베이어 데이터셋의 화각과 실제 AI 추론 시야가 불일치하는 치명적 문제 발생.

---

## 2. 세부 기능 요구사항 (Functional Requirements)

### F-1. 카메라 16:9 광범위 스트림 제약 조건 (`getUserMedia`)
- 카메라 스트림 요청 시 16:9 표준 와이드 화면(720p/360p)과 16:9 종횡비를 명시:
```javascript
const constraints = {
  video: {
    facingMode: { ideal: "environment" },
    width: { ideal: 1280, min: 640 },
    height: { ideal: 720, min: 360 },
    aspectRatio: { ideal: 1.777777778 }
  },
  audio: false
};
```
- 모바일 브라우저 호환성을 위한 지능형 단계별 폴백 체인(16:9 우선 ➔ 환경 카메라 ➔ 기본 카메라) 유지.

### F-2. 모바일 반응형 16:9 뷰포트 레이아웃 (세로/가로 모드 완벽 분기)
- **세로 모드 (Portrait, 화면 폭 < 768px 또는 `orientation: portrait`):**
  - 레이아웃: `flex-direction: column` (상하 배치).
  - 상단 뷰포트: 가로 너비 100% 꽉 채우고, `aspect-ratio: 16 / 9`를 엄격 적용하여 16:9 와이드 전체 화각을 완벽 표시.
  - 하단 사이드바/컨트롤: 높이 나머지 영역(`flex: 1`)을 차지하며 부드럽게 세로 스크롤 가능.
  - 화면 상단에 "가로 회전 권장(Landscape)" 안내 배지 노출.
- **가로 모드 (Landscape):**
  - 레이아웃: `flex-direction: row` (좌우 배치).
  - 좌측 뷰포트: 16:9 비율을 유지하며 화면 높이 전체를 활용한 광범위 와이드 뷰.
  - 우측 사이드바: 고정 너비(220px)로 직관적 조작 유지.

### F-3. 비디오/캔버스 16:9 왜곡 및 잘림(Crop) 방지
- `video`, `#sim-canvas`, `#overlay-canvas`에 대해:
  - 16:9 종횡비 컨테이너 내에서 `object-fit: contain` 또는 1:1 완벽 정합을 적용하여 **상하좌우 단 1픽셀도 잘리지 않는 광범위 16:9 화각 전체** 표시.
  - 오버레이 캔버스의 터치/마우스 ROI 조작 좌표가 16:9 화면 내에서 어긋남 없이 1:1로 정밀하게 매핑되도록 보장.

### F-4. 적용 대상 엔드포인트
- `color.html` (색상/픽셀 AI 검사 모드)
- `light.html` (밝기 AI 검사 모드)
- `index.html` (포털 페이지 내 안내 문구 및 16:9 최적화 강조)

## 3. 검증 기준 (Acceptance Criteria)
1. **코드 정적 분석:**
   - `getUserMedia` 제약 조건에 16:9 (`aspectRatio: 1.777777778` 및 1280x720 / 640x360) 탑재 확인.
   - CSS 미디어 쿼리(세로 모드 column 분기, 가로 모드 row 분기, `aspect-ratio: 16 / 9`) 구현 확인.
   - `video`의 `object-fit: contain` 또는 16:9 전용 래퍼를 통한 화각 잘림 방지 확인.
2. **원샷 통합 QA:**
   - 모바일 세로 뷰포트(390x844) 및 가로 뷰포트(844x390)에서 비디오 뷰포트가 16:9 비율을 유지하고 잘림/왜곡 없이 정상 렌더링되는지 스크립트로 자동 검증.
