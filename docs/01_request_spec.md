# [요구사항 명세서] 고정 가로형(Landscape Fixed) 촬영 화면 및 좌➔우 컨베이어 최적화

## 1. 개요 및 배경 (Background & Objective)
- **사용자 피드백 및 현장 요구:**
  - "화면을 가로로 돌려주세요"와 같은 세로/가로 모드 전환 안내 오버레이(개념)를 전면 제거.
  - 가로/세로 분기 없이 **촬영 및 검사 화면 자체가 무조건 가로(Landscape) 고정값으로 작동**하도록 단일화.
  - 컨베이어 벨트가 **[좌측 ➔ 우측]**으로 주행하는 현장 경로에 맞추어 카메라 뷰, 이송 인디케이터, 통과 판별선을 최적화.
  - 모바일 실기기(Safari/Chrome)에서 카메라 화면이 검은 화면으로 멈추지 않고 후면 카메라 피드가 즉각 100% 렌더링되도록 비디오 생명주기 및 스트림 파이프라인 전면 보강.

---

## 2. 세부 기능 요구사항 (Functional Requirements)

### F-1. 회전 안내 오버레이 제거 및 고정 가로 레이아웃 단일화
1. `#portrait-overlay` 및 `@media (orientation: portrait)` 회전 요청 코드 완전 삭제.
2. 기기 방향과 무관하게 웹앱 전체가 가로형 와이드(16:9) 비율로 고정 렌더링.
3. 카메라 뷰가 우측 패널에 가려지지 않도록 패널 너비를 모바일 맞춤 슬림화(240px 또는 반투명 오버레이)하여 좌➔우 컨베이어 시야를 극대화.

### F-2. 모바일 카메라 재생 보장 및 블랙스크린 방지
1. `video.play()` 명시적 프로미스 처리 및 `playsinline`, `autoplay`, `muted` 속성 완전 강제.
2. 모바일 카메라 해상도 제약 완화:
   - `{ facingMode: { ideal: "environment" }, width: { ideal: 1280 }, height: { ideal: 720 } }` 실패 시 일반 `{ video: true }`로 자동 폴백.
   - 카메라 상태 메시지(권한 허용 대기, 활성화 완료, 오류 시 즉각 안내) UI 오버레이 표시.

### F-3. 컨베이어 좌 ➔ 우 주행 경로 특화
1. 화면 상단에 컨베이어 주행 방향 안내(`[좌 ➔ 우 이송] ▶▶▶`) 가이드라인 시각화.
2. 검사 통과선(Trigger ROI)을 벨트 중앙부(X: 50~60%)에 배치하여 좌측에서 진입하는 상자를 실시간 포착.
3. 가상 컨베이어 모드에서도 상자가 좌측(-100px)에서 우측으로 자연스럽게 주행하도록 경로 동기화.

### F-4. 통과 즉시 0.05초 AI 판별 및 0.1초 경보 유지
1. `inspect_box_posture(box_crop_img)` 표준 더미 및 코랩 ONNX 모델 장착 슬롯 유지.
2. 키보드 't' 및 UI 버튼 불량 주입 시 0.1초 내 붉은색 플래시 경보 및 Web Audio 비프음 즉각 발령.

---

## 3. 검증 기준
1. 모바일 브라우저 진입 시 회전 팝업 없이 즉시 가로형 검사 화면 렌더링.
2. 모바일 후면 카메라 정상 출력 (블랙스크린 0건).
3. 좌➔우 상자 통과 시 진입 순간 크롭 및 0.1초 이내 경보 정상 동작.
